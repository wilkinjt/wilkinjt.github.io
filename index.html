Principles

Procedure before improvisation. If a task matters, it has a written procedure, and the procedure is followed or changed — never skipped.

Verify independently. A check proves something only if it could have failed. I test the test.

Nothing changes unsigned. Every change to a running system is reviewed and approved by a person before it ships — including mine.

Your data stays with you. A system I build runs where the data already lives. Nothing leaves unless you send it.

Hand it over. Documented so the people who own it can run it without me — and the choice to keep me on stays theirs.

Say what it doesn't do. Limits stated up front. Sometimes the right answer is not to build at all.

Silence is the healthy output. A good system reports what changed, or that it can no longer see — not that nothing happened.
